# 随机数生成器 (Random Number Generator)

一个 Windows 桌面小工具，用于生成指定范围内的随机整数。
基于 **Python 3 + tkinter**，无第三方依赖，开箱即用。

作者：hand_jun

## 功能

- 标题「随机数生成器」（黑色加粗大字）+ 作者「hand_jun」（蓝绿色小字）
- 三个按钮：开始生成 / 设置 / 查看历史记录
- 结果区为独立文本框（带滚动条），支持鼠标滚轮滚动查看
- 每次生成会覆盖上一次结果；所有记录写入历史记录窗口
- 历史记录窗口为控制台风格（时间 / 参数 / 结果分色显示，自动滚到最新一条）
- 参数全自动纠正 + 友好报错

## 参数规则

| 参数 | 合法范围 | 自动纠正策略 |
|------|---------|-------------|
| 最小值 | -10000 ~ 10000 | 小数取整、越界钳制 |
| 最大值 | -10000 ~ 10000 | 小数取整、越界钳制、小于最小值自动交换 |
| 每次生成个数 | 1 ~ 50 | 小数取整、越界钳制 |
| 是否重复生成 | √ / × | — |

额外处理：
- 全角数字 / 空格 / 千分位逗号 → 自动清洗
- 空输入 → 使用默认值
- 含非法字符（字母/中文）→ 弹窗报错 + 指正方案 + 焦点定位到出错输入框
- 不允许重复但个数 > 可选数 → 弹窗报错并给出 3 种修改方案
